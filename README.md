# Simulador Las Moreras (versión alumno)

Simulación del servicio de mediodía en el bistró-cafetería Las Moreras para el certificado de profesionalidad HOTR0208 (Operaciones básicas de restaurante y bar).

El alumnado recorre las fases A a D a su ritmo y, al terminar, copia un código de resultados que envía al docente. El progreso se guarda solo en el navegador de cada alumno: esta página no envía ni guarda datos en ningún servidor.
